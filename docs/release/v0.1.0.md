## ภาษาไทย

- Dock วางได้ทั้งสี่ด้าน ปรับความโปร่งและลำดับกลุ่ม Apps, Running และ Zhyprbola ได้
- เปิดแอป สลับหน้าต่าง ลากจัดลำดับไอคอน และเลือกแสดงหน้าต่างแบบรวมกลุ่มหรือแยกไอคอน
- จัด component เป็น Show, Hidden หรือ Quick เพื่อเปิดจาก dock หรือเมนูรวม
- ควบคุมเสียงลำโพงและไมโครโฟนแยกกัน ปรับความสว่าง ดูสถานะแบตเตอรี่ และสลับภาษา
- ปรับรูปแบบวันที่ เวลา ภาษา และการแสดงวินาที
- Show Desktop / Restore ย่อและคืนหน้าต่างด้วยปุ่มบน dock หรือ `Super+0`
- Wi-Fi และ Bluetooth เปิด/ปิด ค้นหา เชื่อมต่อ ตัดการเชื่อมต่อ และดูรายละเอียดได้
- มี animation radar, tab และรายการ พร้อมแสดงสถานะ loading
- แสดงนาฬิกา สภาพอากาศ และสถานะ CPU, RAM และ disk
- Music Player เล่น/หยุด เปลี่ยนเพลง และเลือกตำแหน่งเล่นได้ พร้อม audio spectrum แบบ panel และขอบจอ
- ปฏิทินเปลี่ยนเดือนได้ และ Tasks เพิ่ม แก้ไข ทำเครื่องหมาย ลบ และลากจัดลำดับได้
- Key Visualizer แสดงปุ่มและ shortcut ภาษาอังกฤษ/ไทย ปรับ font size, Padding X/Y, width และ text alignment พร้อม preview
- Screenshots เลือกหลายภาพ คัดลอก path เปิด preview ที่ปรับขนาดได้ และลบพร้อม undo
- เลือกได้แปดธีม พร้อม wallpaper ของธีม และปรับความโปร่งของ panel แยกจาก dock

## English

- Place the dock on any screen edge and customize opacity and the order of Apps, Running, and Zhyprbola groups.
- Launch apps, switch windows, drag icons to reorder them, and choose grouped apps or separate window icons.
- Organize components into Show, Hidden, or Quick for direct dock access or the Components menu.
- Control speaker and microphone audio separately, adjust brightness, view battery status, and switch input sources.
- Customize date/time formats, locale, and seconds.
- Minimize and restore windows with the dock's Show Desktop / Restore button or `Super+0`.
- Turn Wi-Fi and Bluetooth on/off, search, connect, disconnect, and view connection details.
- Radar, tab, and list animations include loading indicators.
- View a clock, weather, and CPU, RAM, and disk status.
- Music Player supports play/pause, track switching, and seeking, with audio spectrum in a panel or along a screen edge.
- Navigate calendar months and add, edit, complete, delete, and reorder tasks.
- Key Visualizer displays keys and shortcuts in English/Thai, with font size, Padding X/Y, width, alignment, and appearance previews.
- Select multiple screenshots, copy paths, open resizable previews, and undo deletion.
- Choose from eight themes and their wallpapers; adjust panel backgrounds independently of dock opacity.
